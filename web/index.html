Access-Tier Definitions

  • Self-serve free (47): Immediate free developer signup with instant API key.
  • Self-serve trial (14): Free developer sandbox or limited trial available self-serve.
  • Paid-plan dependent (33): Requires an active paid subscription tier before API credentials work.
  • Admin approval required (4): Requires manual enterprise review or partner application.
  • Unknown (2): Ambiguous rate tiers (Zoho Cliq) or login-walled portal (FanBasis).

Strict Easy Opportunities Formula

To ensure zero sales friction, an integration is classified as an Easy Opportunity strictly when:

buildability == "Easy" AND
has_public_api == true AND
access_tier IN ["Self-serve free", "Self-serve trial"]

Yields exactly 44 Free + 13 Trial = 57 Opportunities.
